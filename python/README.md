# Python 学习与练习指南

## 章节学习流程

1. **先读官方教程。** 以 [Python 3.13 中文官方教程](https://docs.python.org/zh-cn/3.13/tutorial/index.html) 为主线。开始一章时，按官方目录列出小节和各节知识点，学员先过一遍文档，记下疑问。
2. **按小节交互带练。** 遵循官方顺序，保留每题要练的知识点，换成贴近日常任务或项目的场景与数据。一次练一个新知识点，先让学员预测输出、解释执行顺序或动手修改代码，再给出标准答案和逐步解析。遇到语法疑问时，回看相应的官方示例。
3. **练习后归档并核对覆盖。** 每道带练题都按所属小节归档。每节学完，对照官方教程核对已练的知识点，记下本次还没展开的内容，下次接着学。每日目标用来安排进度。
4. **独立做综合练习和章末测试。** 学完一章后，先独立完成一个串联本章知识点的小练习。章末再次对照官方目录和各节知识点查漏，补齐后用新场景出题，学员独立作答，再批改。覆盖核对和章末测试完成后，更新仓库首页的学习进度。

## 交互练习归档

- 在 `python/` 的对应章节目录内，按官方小节编号和主题命名，例如 `4.1-if 语句.py`。文件开头注明官方小节链接。
- 每题保留题目和代码，讲解后在对应代码附近写标准答案和逐步解析。解析按需要说明条件检查顺序、分支或循环的执行过程、关键变量变化以及输出或返回值。
- 归档采用统一的标准答案和解析格式。练习中的个人作答和点评留在对话里。
- 用代码和注释组织练习，保持脚本可直接运行。故意触发异常的示例保留为注释。

## 章末测试

- 测试文件放在相应章节目录，命名为 `第N章-测试.py`，按教程知识点分节，题号连续。
- 预测题把答案写在对应代码附近，多行输出可逐行写在注释中。保留学员的答案和代码。
- 批改后在每题下方加评分和解析，文件开头写总分，分节标题写小计。算术题写计算步骤，涉及状态变化的题写出执行顺序和关键变量值。
- 用代码和注释组织题目，让脚本可以直接运行。故意触发异常的示例保留为注释。
