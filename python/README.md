# Python 学习与练习指南

## 章节学习流程

1. **先读官方教程。** 以 [Python 3.13 中文官方教程](https://docs.python.org/zh-cn/3.13/tutorial/index.html) 为主线。开始一章时，按官方目录列出小节和各节知识点，学员先过一遍文档，记下疑问。
2. **逐个做官方示例。** 按官方小节和示例的出现顺序带练，每个示例都过一遍。把当前示例放进本地文件，保留官方代码和数据。学员在文件里运行或编辑代码，在聊天里预测输出、解释执行顺序和提出疑问，再一起核对结果。
   - 学员每次回答后，先指出答对了哪些地方、哪些地方需要修正，并解释原因。然后问学员还有没有问题，等学员确认可以继续，再讲下一个示例或知识点。
3. **归档示例并核对覆盖。** 讲完一个示例就在本地补上运行结果和逐步解析。每节学完，对照官方原文核对知识点和示例，记下尚未讲完的位置，下次从那里继续。
4. **学完整章后做新题。** 对照官方目录逐节确认知识点和示例都已覆盖，再用新案例出综合练习和章末测试。学员独立作答，需要写代码时在本地文件中完成。批改后更新仓库首页的学习进度。

## 官方示例归档

- 在 `python/` 的对应章节目录内，按官方小节编号和主题命名，例如 `4.1-if 语句.py`。文件开头注明官方小节链接。
- 同一小节的示例按文档顺序归档。讲解后在对应代码附近写运行结果和逐步解析。解析按需要说明执行顺序、关键变量变化以及输出或返回值。
- 用代码和注释组织示例，保持脚本可直接运行。交互式示例移除 `>>>` 和 `...` 提示符。需要特殊运行方式、故意报错或会一直运行的示例，保留原代码并注明如何单独验证。

## 章末测试

- 测试文件放在相应章节目录，命名为 `第N章-测试.py`，按教程知识点分节，题号连续。
- 预测题把答案写在对应代码附近，多行输出可逐行写在注释中。保留学员的答案和代码。
- 批改后在每题下方加评分和解析，文件开头写总分，分节标题写小计。算术题写计算步骤，涉及状态变化的题写出执行顺序和关键变量值。
- 用代码和注释组织题目，让脚本可以直接运行。故意触发异常的示例保留为注释。
