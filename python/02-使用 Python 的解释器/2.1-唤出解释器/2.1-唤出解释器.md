# [2.1. 唤出解释器](https://docs.python.org/zh-cn/3.13/tutorial/interpreter.html#invoking-the-interpreter)

在 VS Code 打开仓库根目录。以下命令从仓库根目录的 macOS 终端运行。

```sh
source python/.venv/bin/activate
python --version
python
```

在 `>>>` 提示符下输入 `2 + 2`，会显示 `4`。输入 `quit()` 或按 Control + D 回到终端。

```sh
python "python/02-使用 Python 的解释器/2.1-唤出解释器/2.1.2-交互模式.py"
python -c 'print(2 + 2)'
python -m pip --version
python -i "python/02-使用 Python 的解释器/2.1-唤出解释器/2.1.2-交互模式.py"
```

- 第一条运行整个脚本，输出 `Be careful not to fall off!` 后退出。
- `-c` 执行引号里的 Python 代码，这里输出 `4`。
- `-m` 按模块名运行模块，这里输出 pip 版本。
- `-i` 先执行脚本，再进入交互模式。此时输入 `the_world_is_flat`，会显示 `True`。
