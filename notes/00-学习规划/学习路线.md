# 学习路线

1. **Python 基础** — 常用数据结构、函数、类型标注、模块、异常、文件与 JSON、虚拟环境与依赖管理
2. **Python 后端与数据库** — HTTP、FastAPI、Pydantic、异步 I/O、SQL 查询、表连接（JOIN）、事务、PostgreSQL
3. **大模型应用开发** — 大语言模型（LLM）、Token、上下文窗口、模型 API、提示词版本管理、结构化输出、工具调用、服务器发送事件（SSE）、工作流执行状态展示
4. **检索增强生成（RAG）** — 长文档切分、向量嵌入（embeddings）、向量存储与检索、生成与来源引用
5. **Agent 开发**
   - [LangChain](<../04-Agent 开发/01-LangChain.md>) — 模型、工具、系统提示词、`create_agent`
   - [LangGraph](<../04-Agent 开发/02-LangGraph.md>) — 状态、节点、条件边、持久化
   - [Hermes Agent](<../04-Agent 开发/03-Hermes Agent.md>)（选读） — 了解实际项目怎样实现记忆、技能和工具调用
6. **工程化与部署** — Git 工作流、pytest、评估、日志、Docker、技术文档
