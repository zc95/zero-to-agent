# 文档切分、检索与引用

RAG（Retrieval-Augmented Generation，检索增强生成）用检索到的资料为模型生成回答提供上下文。练习时依次掌握文档切分、向量嵌入、检索、生成和来源引用。

## 长文档练习

- 用自拟技术交底材料练习按章节切分，为每个片段保留文档 ID、章节和原文位置。
- 用固定问题检查检索结果能否找到支持答案的片段。遇到证据不足的字段，列出待补充问题。
- PostgreSQL 用于保存文档和任务等业务记录。向量检索可先用 PostgreSQL 的 pgvector 扩展练相似度查询，再按项目需要试用 JD 列出的 Milvus。

## 官方资料

- [LlamaIndex 的 RAG 入门](https://developers.llamaindex.ai/python/framework/understanding/rag/)。用这篇了解文档载入、索引、检索和生成各做什么，再用几段本地文本练习切分、检索和记录来源。
- [pgvector 安装与使用](https://github.com/pgvector/pgvector)。学到用 PostgreSQL 存储向量时，再查扩展安装和相似度查询。
- [Milvus 官方快速入门](https://milvus.io/docs/quickstart.md)
