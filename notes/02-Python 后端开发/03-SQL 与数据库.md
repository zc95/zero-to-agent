# SQL 与数据库

## 官方资料

- [Python 标准库 sqlite3 教程（官方中文）](https://docs.python.org/zh-cn/3/library/sqlite3.html#tutorial) · [英文原文](https://docs.python.org/3/library/sqlite3.html)。先用一个本地数据库文件练建表、参数化查询、提交和回滚。
- [PostgreSQL 官方教程](https://www.postgresql.org/docs/current/tutorial.html)。重点读 SQL 基础、表连接、聚合和事务。
- [PostgreSQL macOS 安装入口](https://www.postgresql.org/download/macosx/)。学到需要连接独立数据库服务时再装。
