# FastAPI 与接口校验

## 官方资料

- [HTTP 概述（MDN 中文）](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Guides/Overview)。从后端视角复习请求方法、状态码和请求头。
- [FastAPI 中文教程](https://fastapi.tiangolo.com/zh/tutorial/)。安装看「第一步」，练习顺序为路径参数、查询参数、请求体、响应模型和错误处理。
- [FastAPI 请求体（中文）](https://fastapi.tiangolo.com/zh/tutorial/body/) · [Pydantic 数据校验](https://pydantic.dev/docs/validation/latest/get-started/)。练用类型和约束校验请求数据。
- [FastAPI 的 async / await（中文）](https://fastapi.tiangolo.com/zh/async/)。看懂同步函数和异步函数的区别，再练一次异步 I/O。
