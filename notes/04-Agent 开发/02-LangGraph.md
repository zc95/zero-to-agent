# LangGraph

## 知识点

- 图 API（Graph API）包括状态（state）、节点（node）、边（edge）和条件边（conditional edge）。
- 学习持久化（persistence）时，理解 checkpointer 如何保存图状态快照。每份快照称为检查点（checkpoint）。
